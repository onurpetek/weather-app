# Petek Weather App

Şehir adına göre güncel hava durumunu ve 5 günlük tahmini gösteren, favori şehirlerin yönetilebildiği çok sayfalı bir hava durumu web sitesi.

## Özellikler
- Şehir arama; sıcaklık, nem ve rüzgar bilgisi
- 5 günlük tahmin tablosu
- Favori şehirler: ekleme, listeleme, güncelleme, silme
- Sıcaklık birimi (°C / °F) ve varsayılan şehir ayarı
- Doğrulamalı geri bildirim formu

## Sayfalar
| Dosya | İçerik |
|---|---|
| index.html | Şehir arama, anlık hava durumu |
| tahmin.html | 5 günlük tahmin |
| favoriler.html | Favori şehirler |
| ayarlar.html | Birim ve varsayılan şehir |
| hakkinda.html | Proje bilgisi, geri bildirim formu |

## Kullanılan Teknolojiler
HTML, CSS (Flexbox/Grid), JavaScript, OpenWeatherMap API, localStorage

## Geliştirme Durumu
Proje 9 haftalık bir plana göre geliştiriliyor. Şu an 1. hafta tamamlandı (proje iskeleti).
