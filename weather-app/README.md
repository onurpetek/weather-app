# Petek Weather App

Şehir adına göre güncel hava durumunu ve 5 günlük tahmini gösteren, favori şehirlerin yönetilebildiği çok sayfalı hava durumu web sitesi.

## Özellikler
- Şehir arama, anlık sıcaklık / nem / rüzgar bilgisi
- 5 günlük tahmin tablosu
- Favori şehirler (ekle, listele, güncelle, sil)
- Sıcaklık birimi (°C/°F) ayarı
- Geri bildirim formu

## Sayfalar
| Dosya | İçerik |
|---|---|
| index.html | Şehir arama, anlık hava durumu |
| tahmin.html | 5 günlük tahmin |
| favoriler.html | Favori şehirler |
| ayarlar.html | Birim ve varsayılan şehir |
| hakkinda.html | Proje bilgisi, geri bildirim formu |

## Teknolojiler
HTML, CSS, JavaScript, OpenWeatherMap API, localStorage

## Kurulum
1. `config.example.js` dosyasını `config.js` olarak kopyala.
2. İçine kendi OpenWeatherMap API anahtarını yaz.
3. `index.html` dosyasını tarayıcıda aç.
